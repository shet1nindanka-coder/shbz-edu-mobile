# ШБЗ Школа — мобильное приложение

Приложение для телефона (Android и iPhone), которое повторяет сайт «ШБЗ Школа» для трёх ролей: ученик,
учитель, разработчик. Интерфейс на русском и английском, есть светлая и тёмная тема.

**Сейчас приложение работает на демо-данных.** Настоящего сервера у него пока нет: все ученики, темы,
домашние задания, уроки и «проверки ИИ» — выдуманные и хранятся прямо в телефоне. Всё, что вы нажимаете
(выдать ДЗ, отметить номер, записать звонок), сохраняется только на этом телефоне и ни на сайт, ни к другим
людям не попадает. Данные можно в любой момент вернуть к исходным (см. «Экран „Демо-данные“»).

Сайт — отдельный репозиторий, это приложение его не меняет.

## Как запустить на своём телефоне

Нужны компьютер и телефон. Ничего собирать и публиковать в магазинах не требуется: приложение открывается
внутри бесплатной программы **Expo Go**.

1. **На компьютере установите Node.js версии 22 (LTS) или 24** — с сайта nodejs.org. Версия 20 не подойдёт:
   Expo SDK 58 требует Node 22.13 или новее. Проверить версию: `node -v`.
2. **На телефоне установите Expo Go** из Google Play или App Store. Нужна свежая версия, которая
   поддерживает Expo SDK 58 (если Expo Go скажет, что проект сделан для другой версии SDK, — обновите Expo Go).
3. Откройте терминал в папке проекта и установите зависимости (один раз, занимает несколько минут):

   ```bash
   npm install
   ```

4. Запустите проект:

   ```bash
   npx expo start
   ```

   В терминале появится QR-код.
5. **Телефон и компьютер должны быть в одной сети Wi-Fi.** Отсканируйте QR-код:
   - Android — кнопкой «Scan QR code» внутри Expo Go;
   - iPhone — обычной камерой, затем нажмите на появившуюся ссылку «Открыть в Expo Go».
6. Первый запуск занимает до минуты (на компьютере собирается приложение). Дальше откроется экран входа.

Если телефон не подключается (другая сеть, гостевой Wi-Fi, VPN, корпоративный роутер), запустите так:

```bash
npx expo start --tunnel
```

При первом запуске с `--tunnel` Expo предложит установить дополнительный пакет `@expo/ngrok` — согласитесь.
Через туннель всё работает медленнее, но одна сеть уже не нужна.

Остановить проект — `Ctrl+C` в терминале. Чтобы приложение на телефоне перечитало код — встряхните телефон и
выберите «Reload».

### Что в Expo Go работает не так, как в готовом приложении

- На Android при запуске может появиться жёлтое предупреждение о том, что push-уведомления в Expo Go
  недоступны. Это ожидаемо: приложение использует только локальные напоминания, они работают.
- Вход по биометрии: на iPhone внутри Expo Go вместо Face ID может запрашиваться код-пароль телефона.
- Иконка и заставка в Expo Go — от самого Expo Go, а не от «ШБЗ Школы».

## Экран «Демо-данные»

Служебный экран, которого нет на сайте и не будет в настоящем приложении. Открывается двумя способами:

- экран входа → «Демо-аккаунты» → «Показать» → строка **«Демо-данные и переключатели»**;
- после входа: шестерёнка (настройки) → внизу раздел «Разделы» → **«Демо-данные»**.

Для чего он нужен:

- **«Сбросить демо-данные»** — вернуть всё к исходному состоянию (после экспериментов или если что-то
  запуталось). Данные и сами сбрасываются раз в сутки, это можно отключить переключателем рядом.
- **Network** — замедлить ответы «сервера», включить режим «нет интернета», заставить следующий запрос
  завершиться ошибкой: так проверяется, как приложение ведёт себя при плохой связи.
- **AI checks / AI plans** — выбрать, чем закончится следующая проверка решения или подбор заданий
  (верно, неверно, не распознано, ошибка, очередь переполнена, лимит исчерпан).
- **Limits** — исчерпать или очистить ограничения на частоту действий.
- **Lesson** — заново запустить урок, который «начинается через минуту».

Подписи на этом экране на английском: он сделан для проверки, а не для пользователей.

## Команды проекта

```bash
npx expo start        # запустить для телефона (Expo Go)
npx expo start --web  # открыть в браузере на компьютере
npm run typecheck     # проверка типов TypeScript — должна проходить без ошибок
npm run lint          # проверка стиля кода — без предупреждений
npm run test          # автоматические тесты логики (около 1600, без телефона и сети)
npm run export:web    # собрать веб-версию в папку dist (так проверяются экраны без телефона)
npm run sync:i18n -- <папка сайта>   # обновить тексты интерфейса из репозитория сайта
```

Перед любым изменением кода и после него: `npm run typecheck`, `npm run lint`, `npm run test`.

## Что пока не настоящее

- **Сервер.** Его роль играет встроенный «мок» (`src/mock`, 112 методов): он проверяет права и лимиты и
  отвечает теми же ошибками, что и сайт, но живёт внутри приложения. Подключение к настоящему серверу
  (`HttpApiClient`) ещё не написано; экраны при этом переделывать не придётся — они работают через общий
  контракт `ApiClient` (`docs/spec/00-unified-contract.md`).
- **Проверка решений и подбор заданий ИИ** — имитация с заранее заданными исходами, настоящая модель не
  вызывается.
- **Файлы** (теория, задания, раздатки, фото решений) — заранее подготовленные образцы; фото, которые вы
  прикрепите сами, остаются на телефоне.
- **Push-уведомления с сервера** не подключены. Работают только локальные напоминания, которые телефон
  ставит себе сам (дедлайн ДЗ, начало урока, звонки родителям).
- **Обновления в реальном времени** имитируются внутри приложения.
- **Сборка для магазинов** (EAS, подписи, публикация) не настроена: `eas.json` в проекте нет.
- На настоящем телефоне приложение до сих пор не запускалось: проверены веб-версия и сборка пакетов для
  Android и iOS. Поведение клавиатуры, жестов, камеры, биометрии и уведомлений нужно смотреть на устройстве.

## Как устроены папки

- `src/app` — адреса экранов (маршруты), `src/screens` — сами экраны по разделам: ученик, учитель, занятия,
  группы, звонки, статистика, темы, разработчик, общая оболочка.
- `src/ui`, `src/components`, `src/theme` — кнопки, карточки, поля, формулы, просмотр файлов, цвета и шрифты.
- `src/api` — описание запросов к серверу; `src/mock` — встроенный демо-сервер и его данные (`fixtures`).
- `src/domain`, `src/services`, `src/providers`, `src/navigation`, `src/i18n`, `src/lib/i18n` — правила
  (даты по Москве, статусы, посещаемость), работа с телефоном (хранилище, сеть, уведомления, камера),
  сессия, переходы между экранами, тексты на двух языках.
- `docs/spec` — спецификация, снятая с сайта; `docs/foundation.md` — справочник по общим слоям;
  `tests` — тесты; `CLAUDE.md` и `AGENTS.md` — правила для разработчиков и ИИ-агентов.
